# zav — אינדיקטורים טכניים עם tvscreener

תיקייה עצמאית שמושכת אינדיקטורים טכניים מוכרים (טווח יומי) מ-TradingView באמצעות הספרייה [tvscreener](https://github.com/deepentropy/tvscreener), ומוסיפה תוויות סיגנל פשוטות לכל מניה.

## האינדיקטורים

- **RSI(14)** — מתנד מומנטום בין 0 ל-100. מתחת ל-30 = מכירת יתר, מעל 70 = קניית יתר.
- **MACD (12,26,9)** — קו MACD, קו סיגנל והיסטוגרמה. MACD מעל הסיגנל = מומנטום חיובי.
- **SMA50 / SMA200** — ממוצעים נעים פשוטים. SMA50 מעל SMA200 = "צלב זהב" (golden), מתחת = "צלב מוות" (death).
- **EMA20** — ממוצע נע מעריכי קצר טווח; מחיר מעליו מעיד על מגמה קצרה חיובית.
- **רצועות בולינגר (20)** — רצועה עליונה/תחתונה. `bb_pos_pct` = מיקום המחיר בתוך הרצועה (0–100%). רוחב מתחת ל-5% מהמחיר = "squeeze" (התכווצות).
- **סטוכסטי %K/%D (14,3,3)** — מתחת ל-20 מכירת יתר, מעל 80 קניית יתר.
- **ADX(14)** — עוצמת מגמה (ללא כיוון). מעל 25 = שוק במגמה.
- **ATR(14)** — טווח תנודה ממוצע, בדולרים.
- **Relative Volume** — מחזור יחסית לממוצע. מעל 1 = פעילות גבוהה מהרגיל.
- **Technical Rating (`Recommend.All`)** — דירוג טכני של TradingView בין ‎-1 ל-‎+1 (Strong Sell ← → Strong Buy).

## סיגנל מסכם
ציון מ-4 בדיקות: מחיר מול SMA200, MACD מול סיגנל, SMA50 מול SMA200, מחיר מול EMA20.
‎+3 ומעלה = BULLISH, ‎-3 ומטה = BEARISH, אחרת MIXED. מתווספות הערות: overbought / oversold / strong trend.

## הרצה

```bash
pip install -r requirements.txt
python run.py                 # רשימת ברירת מחדל (13 מניות)
python run.py NVDA AAPL MSFT  # רשימה מותאמת
```

הפלט: טבלה במסך + קובץ `results/<תאריך>.csv`.
כפילויות OTC מסוננות: רק התאמה מדויקת של סימול ובורסה NASDAQ/NYSE.
